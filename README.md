# sac-data-grid

A spreadsheet-grade, editable data table for [SACRVM APPKIT](https://github.com/SACRVM/sacrvm-appkit) apps.

**Features:**
- Virtualized rows, fixed header and footer, frozen columns.
- Pagination or incremental loading.
- Inline editing with the kit's own fields.
- Excel-style keyboard, clipboard and undo.

**Status:** specification. See [`SPEC.md`](SPEC.md). Zero build: plain files, vendored kit.
